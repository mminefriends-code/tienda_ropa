# FUENTES — assets de producto

## Poleras (variantes de color)

Archivos originales (referencia):

| Archivo original     | Color  |
|----------------------|--------|
| `polera blanca.png`  | Blanco |
| `polera gris.png`    | Gris   |
| `polera negra.png`   | Negro  |

**Uso en la app** (copiados y renombrados para URLs limpias):

```
PROTOTIPO/web/public/productos/polera/
  blanca.png
  gris.png
  negra.png
```

URLs públicas:

- `/productos/polera/blanca.png`
- `/productos/polera/gris.png`
- `/productos/polera/negra.png`

Estas rutas se vinculan al producto en BD (`producto_imagenes`) y la ficha cambia la foto al elegir el color.
